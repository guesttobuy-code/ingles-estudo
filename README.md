# Estudo de inglês

Repositório privado com todo o material de estudo de inglês do Rafael: uma metodologia de
verbos e montagem de frases, vocabulário Oxford 5000 com tradução e frase de aplicação, e
drills para falar em voz alta. Nível de partida: A2, regressão deliberada ao básico.

## As regras do método

- **Feijão com arroz:** um conceito por aula; repetir à exaustão; só avança quando o checkpoint sai sem pensar.
- **Releitura:** toda lição nova começa relendo o REVISAO-GERAL.
- **Falar em voz alta**, sempre: a terceira passada de cada drill mede a boca, não o olho.
