# B2+-02 — palavras 101 a 200 (coincidence → elbow)

> Ciclo de 10 dias · 10 palavras/dia · Suplemento Oxford 5000, nível B2.
> Regra: cartão no Anki sempre com a FRASE, e falar cada frase 5x em voz alta.

## Dia 1 — palavras 101-110
- [ ] feito

**coincidence** *(substantivo)* — coincidência
*By coincidence, the interviewer and I had worked with the same client.* → Por coincidência, o entrevistador e eu tínhamos trabalhado com o mesmo cliente.

**collector** *(substantivo)* — colecionador; cobrador
*He is a collector of vintage computers from the eighties.* → Ele é colecionador de computadores antigos dos anos oitenta.

**colony** *(substantivo)* — colônia
*Brazil was a Portuguese colony for more than three centuries.* → O Brasil foi uma colônia portuguesa por mais de três séculos.

**colourful** *(adjetivo)* — colorido (EUA: colorful)
*The new dashboard uses a colourful palette that highlights key metrics.* → O novo dashboard usa uma paleta colorida que destaca as métricas principais.

**comic** *(adjetivo, substantivo)* — cômico; história em quadrinhos
*He explained the bug with a comic drawing on the whiteboard.* → Ele explicou o bug com um desenho cômico no quadro branco.

**commander** *(substantivo)* — comandante
*The commander coordinated the rescue operation from the control center.* → O comandante coordenou a operação de resgate do centro de controle.

**comparative** *(adjetivo)* — comparativo
*We prepared a comparative analysis of the three cloud providers.* → Preparamos uma análise comparativa dos três provedores de nuvem.

**completion** *(substantivo)* — conclusão
*Payment is released only after the completion of each project phase.* → O pagamento é liberado apenas após a conclusão de cada fase do projeto.

**compose** *(verbo)* — compor, redigir
*Take a few minutes to compose a clear answer before replying.* → Reserve alguns minutos para compor uma resposta clara antes de responder.

**composer** *(substantivo)* — compositor
*The film's composer won an award for the soundtrack.* → O compositor do filme ganhou um prêmio pela trilha sonora.

## Dia 2 — palavras 111-120

*We wrote comprehensive documentation so new developers can start quickly.* → Escrevemos uma documentação abrangente para que novos desenvolvedores comecem rápido.

**concrete** *(adjetivo, substantivo)* — concreto

**confess** *(verbo)* — confessar

**conservation** *(substantivo)* — conservação, preservação

**considerable** *(adjetivo)* — considerável
*Automating the reports saved a considerable amount of time every week.* → Automatizar os relatórios economizou um tempo considerável toda semana.

**convention** *(substantivo)* — convenção
