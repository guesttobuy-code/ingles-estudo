## Dia 1 — palavras 601-610
- [ ] feito

*Access to production data is strictly limited to the on-call team.* → O acesso aos dados de produção é estritamente limitado ao time de plantão.

**stroke** *(substantivo)* — derrame, AVC; golpe, traço
*Landing that client was a stroke of luck that changed the company.* → Fechar aquele cliente foi um golpe de sorte que mudou a empresa.

**stunning** *(adjetivo)* — deslumbrante, impressionante
*The designer delivered a stunning landing page in just two days.* → A designer entregou uma landing page deslumbrante em só dois dias.

**subsequent** *(adjetivo)* — subsequente, posterior
*The first release had bugs, but subsequent versions were much more stable.* → A primeira versão tinha bugs, mas as versões subsequentes foram bem mais estáveis.

**subsequently** *(advérbio)* — subsequentemente, posteriormente
*The feature was tested internally and subsequently released to all users.* → A funcionalidade foi testada internamente e posteriormente liberada para todos os usuários.

**suburb** *(substantivo)* — subúrbio, bairro afastado
*He moved to a quiet suburb and works remotely for a US startup.* → Ele se mudou para um bairro afastado e tranquilo e trabalha remotamente para uma startup americana.

**suffering** *(substantivo)* — sofrimento
*Good error messages reduce the suffering of users and support teams.* → Boas mensagens de erro reduzem o sofrimento dos usuários e dos times de suporte.

**sufficient** *(adjetivo)* — suficiente
*One week is sufficient to build a working prototype of this idea.* → Uma semana é suficiente para construir um protótipo funcional dessa ideia.

**sufficiently** *(advérbio)* — suficientemente
*The model wasn't sufficiently accurate, so we kept a human in the loop.* → O modelo não era suficientemente preciso, então mantivemos um humano no processo.

**super** *(adjetivo)* — super, ótimo
*The onboarding call was super helpful for understanding the codebase.* → A chamada de onboarding foi super útil para entender a base de código.
