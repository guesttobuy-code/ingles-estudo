# C1-10 — palavras 901 a 1000 (presumably → resignation)

> Ciclo de 10 dias · 10 palavras/dia · Suplemento Oxford 5000, nível C1.
> Regra: cartão no Anki sempre com a FRASE, e falar cada frase 5x em voz alta.

## Dia 1 — palavras 901-910
- [ ] feito

**presumably** *(advérbio)* — presumivelmente, supostamente
*The API is down, so presumably the team is already investigating the root cause.* → A API está fora do ar, então presumivelmente o time já está investigando a causa raiz.

**presume** *(verbo)* — presumir, supor
*I presume you have already reviewed the pull request I opened yesterday.* → Presumo que você já tenha revisado o pull request que abri ontem.

**prevail** *(verbo)* — prevalecer
*In the end, the simpler architecture prevailed over the more ambitious proposal.* → No fim, a arquitetura mais simples prevaleceu sobre a proposta mais ambiciosa.

**prevalence** *(substantivo)* — prevalência
*The prevalence of remote work has changed how engineering teams communicate.* → A prevalência do trabalho remoto mudou a forma como times de engenharia se comunicam.

**prevention** *(substantivo)* — prevenção
*Good logging is about prevention: you catch problems before users notice them.* → Um bom log é sobre prevenção: você pega os problemas antes que os usuários percebam.

**prey** *(substantivo)* — presa
*Startups without clear focus become easy prey for larger competitors.* → Startups sem foco claro viram presa fácil para concorrentes maiores.

**principal** *(substantivo)* — diretor(a) de escola; principal
*The school principal invited local tech companies to talk to the students.* → A diretora da escola convidou empresas de tecnologia locais para conversar com os alunos.

**privatization** *(substantivo)* — privatização
*The privatization of the airport attracted several international investors.* → A privatização do aeroporto atraiu vários investidores internacionais.

**privilege** *(substantivo)* — privilégio
*Working with a team this talented is a privilege I don't take for granted.* → Trabalhar com um time tão talentoso é um privilégio que eu não considero garantido.

**probe** *(substantivo, verbo)* — investigação, sonda; investigar
*The interviewer probed deeper into how I handle conflict within a team.* → O entrevistador investigou mais a fundo como eu lido com conflito dentro de um time.
