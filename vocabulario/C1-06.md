# C1-06 — palavras 501 a 600 (film-maker → inadequate)

> Ciclo de 10 dias · 10 palavras/dia · Suplemento Oxford 5000, nível C1.
> Regra: cartão no Anki sempre com a FRASE, e falar cada frase 5x em voz alta.

## Dia 1 — palavras 501-510
- [ ] feito

**film-maker** *(substantivo)* — cineasta (EUA: filmmaker)
*The film-maker used AI tools to cut the documentary's production time in half.* → O cineasta usou ferramentas de IA para cortar pela metade o tempo de produção do documentário.

**filter** *(substantivo, verbo)* — filtro; filtrar
*We added a filter to the dashboard so managers can see only their own teams.* → Adicionamos um filtro ao painel para que os gestores vejam apenas as próprias equipes.

**fine** *(substantivo, verbo)* — multa; multar
*The company paid a heavy fine for storing customer data without proper consent.* → A empresa pagou uma multa pesada por armazenar dados de clientes sem o consentimento adequado.

**firearm** *(substantivo)* — arma de fogo
*The new regulation requires every firearm sale to be registered in a national database.* → A nova regulamentação exige que toda venda de arma de fogo seja registrada num banco de dados nacional.

**fit** *(substantivo)* — encaixe, adequação, compatibilidade
*Investors kept asking whether we had found real product-market fit before scaling the team.* → Os investidores viviam perguntando se tínhamos encontrado um encaixe real entre produto e mercado antes de escalar o time.

**fixture** *(substantivo)* — item fixo, instalação; jogo do calendário (esporte)
*The morning stand-up became a fixture in our routine after the team went remote.* → A reunião diária matinal virou um item fixo na nossa rotina depois que o time ficou remoto.

**flaw** *(substantivo)* — falha, defeito
*The security review found a serious flaw in how the API handles expired tokens.* → A revisão de segurança encontrou uma falha grave em como a API trata tokens expirados.

**flawed** *(adjetivo)* — falho, defeituoso
*The pricing model was flawed because it ignored how customers actually use the product.* → O modelo de preços era falho porque ignorava como os clientes realmente usam o produto.

**flee** *(verbo)* — fugir (de)
*Thousands of families had to flee the city when the flooding reached the residential areas.* → Milhares de famílias tiveram de fugir da cidade quando a enchente alcançou as áreas residenciais.

**fleet** *(substantivo)* — frota
*Our platform tracks the delivery fleet in real time and predicts maintenance needs.* → Nossa plataforma rastreia a frota de entregas em tempo real e prevê necessidades de manutenção.
